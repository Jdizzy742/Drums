# Year 4, Fall

**UNT equivalent:** Level 4.2  
**Focus:** Your sound. Pull everything together.

## UNT courses this mirrors
- Applied Drum Set
- MUJS 3800 Jazz Conducting and Ensemble Techniques
- Jazz ensemble or combo
- Senior recital planning

## Goals
- Personal sound: tuning, cymbals, touch
- Fluent in every style from the past 7 semesters
- Record a 3-song demo
- Pick and arrange the senior recital program

## Drum set (applied lessons)

### Unit 1: Sound (weeks 1-3)
- [ ] Tune the kit for jazz and for funk; record both
- [ ] Dynamics: play every groove at pp, mf, ff
- [ ] Choose and describe your cymbal sound

### Unit 2: Style review (weeks 4-6)
- [ ] Run every jury from S0 to S6 once; note weak spots
- [ ] Fix the 3 weakest items
- [ ] Swing at 300 bpm (stretch goal)

### Unit 3: Leading a band (weeks 7-9)
- [ ] Run a rehearsal: give tempos, cues, and feedback
- [ ] Conduct (or count off and cue) a big band chart

### Unit 4: Demo (weeks 10-12)
- [ ] Record a 3-song demo in 3 styles
- [ ] Choose 6-8 recital tunes and write set notes

## Musicianship (theory, ear, keyboard)
- [ ] Conducting: basic beat patterns in 2, 3, 4
- [ ] Arrange 2 recital tunes for your band

## Listening
- Chris Dave, Robert Glasper Experiment, Black Radio
- Antonio Sanchez, Migration
- Nate Smith, Kinfolk

## Tunes to learn
- Recital program tunes

## Jury (weeks 13-16)
Record yourself. Pass every item before moving on.

- [ ] Full style review: swing, brushes, Latin, funk, odd meter
- [ ] Present the 3-song demo
- [ ] Recital program approved (by teacher or self-review)
