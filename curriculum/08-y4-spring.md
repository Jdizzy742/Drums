# Year 4, Spring

**UNT equivalent:** Senior Recital  
**Focus:** The senior recital.

## UNT courses this mirrors
- Applied Drum Set
- MUJS 4720 Senior Recital Capstone
- Jazz ensemble or combo

## Goals
- Perform a 45-minute recital
- Show range: swing, brushes, Latin, funk, odd meter, original
- Record it as your capstone

## Drum set (applied lessons)

### Unit 1: Rehearse (weeks 1-6)
- [ ] Weekly run-throughs of the full program
- [ ] Book a venue, band, and date

### Unit 2: Preview (weeks 7-10)
- [ ] Preview performance for friends or teacher
- [ ] Fix issues from the preview

### Unit 3: Perform (weeks 11-14)
- [ ] Perform the recital
- [ ] Record and archive it

## Musicianship (theory, ear, keyboard)
- [ ] Write program notes for each tune

## Listening
- Re-listen to every album from Semester 0. Notice what you hear now.

## Tunes to learn
- Your recital program

## Jury (weeks 13-16)
Record yourself. Pass every item before moving on.

- [ ] Senior recital performed and recorded
