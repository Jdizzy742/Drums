# Course Catalog

Every course in the UNT BM in Jazz Studies (Instrumental), from the 2025-26 semester plan, mapped to this self-study program. Use it to see what's coming and pick what to build out.

**Status key**
- **Built:** weekly lessons and a jury exist in the tracker
- **Outline:** listed in the tracker as a one-line task; lessons, readings, and quizzes not written yet
- **Not included:** university core course, not music

## Building out a course

When you're ready for a course, ask for it by name (for example, "build out Theory I"). A built-out course gets:

- Weekly lesson notes written for a drummer
- Exercises or homework
- A quiz or test at the end of each unit
- Links to free material where it's good (for example, musictheory.net)

Classroom course descriptions here are summaries of what these courses typically cover. They are not UNT's official course descriptions.
